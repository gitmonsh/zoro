# Zoro Project Summary

Zoro is a local-first personal desktop assistant that can talk with the user, understand what is on screen, remember useful information, search the web, help with coding, and automate simple tasks while keeping data private on the laptop.

## Core Features

- Start and stop button
- Wake word: "Zoro"
- Conversation mode
- Natural voice replies
- Floating assistant widget
- Screen watching
- Screen question answering
- Cursor awareness
- Local memory
- Memory dashboard
- Web search
- Browser automation
- Coding help
- Proactive suggestions
- Permission system
- Action log and undo
- Free local mode
- Optional cloud boost
